# Incidents

Postmortems for incidents caused by vkong-connect: a duplicate or leftover rental,
unexpected billing, or output reported as published but missing. Each incident also
has a GitHub issue labeled `incident` that tracks status and follow-ups. Process:
[issue-workflow.md](../issue-workflow.md#incidents).

File name: `YYYY-MM-DD-<slug>.md`. Start from what the user experienced, then impact,
timeline, technical cause, and closing criteria. This repository is public: never
include secrets, signed URLs, or private account/workspace data.
